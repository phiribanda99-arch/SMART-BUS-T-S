Import instructions (quick):

1. Start MySQL (via XAMPP/WAMP).
2. In phpMyAdmin create database `smart_bus` (optional, schema.sql creates it).
3. Import `db/schema.sql` then `db/sample_data.sql`.
4. Generate admin hash using: php -r "echo password_hash('Admin@123', PASSWORD_DEFAULT) . PHP_EOL;"
5. Update `users` record for admin with the generated hash.

Default admin credentials (after step 4/5):
- Email: admin@example.com
- Password: Admin@123

Proceed to Step 2 to create `config.php` and setup scripts.
